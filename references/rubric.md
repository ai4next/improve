# 九维评分表（canonical source）

> `SKILL.md` §「双轨评估」引用本文件。**维度定义、权重、评估轨、评分规则只有这一份。**
> 权重与评估轨的镜像在 `scripts/audit.py` 的 `DIM_WEIGHTS` / `DIM_MODE`，
> `tests/test_selfcheck.py` 断言两者不漂移。

## 1. 九维总表

总分 100。**评估轨决定谁有权给这一维打分。**

| 维度 | 名称 | 权重 | 评估轨 |
|---|---|---|---|
| dim1 | Frontmatter 质量 | 7 | machine |
| dim2 | 工作流清晰度 | 12 | hybrid |
| dim3 | 失败模式编码 | 12 | machine |
| dim4 | 检查点设计 | 6 | machine |
| dim5 | 可执行具体性 | 18 | machine |
| dim6 | 资源整合度 | 4 | machine |
| dim7 | 整体架构 | 12 | hybrid |
| dim8 | 实测表现 | 23 | judge |
| dim9 | 反例与黑名单 | 6 | machine |

**三条轨的含义**：

| 轨 | 覆盖权重 | 谁定分 | 为什么 |
|---|---|---|---|
| `machine` | 53 | `scripts/audit.py` 的诊断惩罚 | 可判定 → 零噪音、可复现 |
| `hybrid` | 24 | 脚本给**上界**，judge 只能**下修**，且必须带行号证据 | 「顺不顺」不可判定，但「有没有明显结构缺陷」可判定 |
| `judge` | 23 | 独立 judge + 回归测试 | 只能实测，无法静态判定 |

> **为什么 judge 只能下修不能上修**：LLM-as-judge 的系统性偏差是**乐观**的。
> 让它给绝对分，它会往高了给；把机器分设成上界、只允许它扣分并要求指名证据，
> 乐观偏差就被结构性掐掉了。**这覆盖了 77% 的权重，只剩 23% 暴露在 judge 噪音里。**

## 2. 维度判据

### dim1 · Frontmatter 质量（7，machine）

判据：`FM001`–`FM011`。核心是**入口三件事**——叫什么（name 合法且与目录一致）、
什么时候被选中（description 有触发词）、什么时候不该被选中（不适用边界）。

评分锚点：

| 分 | 状态 |
|---|---|
| 10 | 无任何 FM 诊断 |
| 7–9 | 只有 info 或单个 warn |
| 4–6 | 有 warn 组合（如无边界 + 有空话尾巴） |
| 1–3 | 有 error（缺 name / description / 超长 / 未闭合） |

### dim2 · 工作流清晰度（12，hybrid）

判据：`ST002`（有没有流程章节）、`ST003`（流程有没有编号）。脚本只判**存在性与有序性**，
判不了「顺序合不合理、每步够不够具体」——那部分由 judge 下修。

### dim3 · 失败模式编码（12，machine）

判据：`FL001`–`FL003`。**只写正向流程而不写失败分支，是 skill 最常见的致命伤**：
agent 一遇异常就卡住，或者开始自由发挥。

编码标准是**三段式**（触发条件 / 一线修复 / 仍失败兜底），不是「注意不要出错」式叮嘱。

### dim4 · 检查点设计（6，machine）

判据：`CP001`–`CP002`。关键决策（不可逆动作、写盘、发布、删除）之前必须有**显性视觉标记**。

### dim5 · 可执行具体性（18，machine）

判据：`SP001`–`SP003`。权重最高的 machine 维度——**具体性直接决定 skill 能不能被执行**。
软化措辞是这一维的主要失分点：它把决定权推回给 agent，等于没写。

### dim6 · 资源整合度（4，machine）

判据：`ST004`（悬空引用）、`ST005`（有没有路由表）、`SZ002`（README 与 name 对不对得上）。
权重低，但 `ST004` 是 error——**引用一个不存在的文件，agent 会直接卡住**。

### dim7 · 整体架构（12，hybrid）

判据：`ST001`、`ST007`–`ST010`、`SZ001`、`RT001`–`RT003`。脚本判结构与 runtime 中立性，
judge 判「层次是否清晰、有无冗余」。

### dim8 · 实测表现（23，judge）

**权重最高，且只能实测。** 判据是回归测试：用 `test-prompts.json` 里的 prompt，
带 skill 跑一遍、不带 skill 跑一遍（baseline），对比输出质量。协议见
[`evidence-gates.md`](evidence-gates.md) §4。

**无 full_test 时 dim8 记 `unverified`，不参与总分**，并在报告里显式列出。
不允许用「干跑推演」给 dim8 打分——那等于编造 23 分。

### dim9 · 反例与黑名单（6，machine）

判据：`ST006`、`SF001`、`SF002`。只写「应该做 X」没有「不要做 Y」的 skill，
缺的是**否定面**——而否定面恰恰是 agent 最容易踩的地方。

## 3. 评分规则

### 3.1 单维度得分（machine / hybrid）

```
penalty(dim) = Σ 该维度上每条诊断的惩罚
  error = 4.0 ｜ warn = 1.5 ｜ info = 0.5
score(dim)   = max(1.0, 10.0 − penalty)          # 下限 1.0，不给 0
```

### 3.2 结构分

```
结构分 = Σ(score(dim) × weight(dim)) / Σ(weight(dim)) × 10      # dim 取 machine + hybrid
```

覆盖权重 77/100。**dim8 不参与**——它没测。

> ⚠️ **结构分是确定性代理指标，不是质量真值。** 它只保证两件事：**可复现**与**单调**
> （诊断变少，分不会变低）。它的用途是**闸门**，不是拿来宣称「质量提升了 12 分」。
> 对外汇报时，结构分与实测表现必须**分开写**。

### 3.3 总分

```
总分 = Σ(score(dim) × weight(dim)) / Σ(已测 dim 的 weight) × 10
```

未测维度进 `unverified` 列表。**归一化后必须显式标注覆盖了哪些维度**——
`77/100` 和 `100/100` 的 85 分不是一回事。

### 3.4 绝对分只做 triage

**绝对总分只用来粗排「先改哪个 skill」，绝不用于 keep/revert。**
理由见 §4。

## 4. 为什么 keep/revert 不用绝对分

LLM judge 给的是**抽样，不是测量**。分数住在「文字 × 该 judge 当下选的标准」里，
不是文字属性。所以：

- 同一份**未改**的文字换个 judge 评，总分可以摆动 **±8**（本机实测）
- 一次保守编辑的真实增益通常是 **+3 ~ +8**
- 拿两次不同 judge 的绝对分相减，差值大半是**换尺**，不是质量变化

**类比**：绝对分 = 用两台未校准的磅秤量节食前后，差值大半是磅秤差；
paired 比较 = **同一台磅秤**量前后，误差相减抵销。

**结论**：绝对分降级为 triage；keep/revert 一律走
[`evidence-gates.md`](evidence-gates.md) 的两道闸门。

## 5. 实证基础

| 来源 | 结论 | 本 skill 怎么用 |
|---|---|---|
| SkillLens（arXiv 2605.23899） | LLM-as-judge 判两份 skill 哪份更好的准确率仅 **46.4%**（低于抛硬币）；加入 meta-skill 三维度后升到 **73.8%** | ① judge 不做绝对分，只做 paired；② 三个 meta 维度落地为 dim3 / dim5 / dim9 |
| SkillLens | 25% 的案例出现 **negative transfer**（加 skill 比不加还差） | dim8 必须带 baseline 对照，不能只看「带 skill 的输出好不好」 |
| 本机 controlled study | 4 类劣化（模糊化 / 删检查点 / 删异常表 / 插废话）→ 5 个独立 judge **5/5** 一致判出 V1>V2，Δ 均值 +46.5 | rubric 能识别 **gross degradation** |
| 同一 study | 但这**不能**证明细粒度差异也可靠 | 所以 fine-grained 决策必须 paired + 人审 |

**读法**：73.8% 意味着**每 4 次判断仍有约 1 次是错的**。这就是为什么
[`evidence-gates.md`](evidence-gates.md) 要求奇数 N 多数决、并且保留人工检查点。
